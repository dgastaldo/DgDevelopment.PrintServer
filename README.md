# PrintServer

Mini print server multipiattaforma (Windows, macOS, Linux) in C# / ASP.NET Core 10: osserva una cartella, mette i file in una coda persistente (SQLite) e li invia alla stampante, tenendo traccia di stato, errori e storico.

> Stato: in fase di avvio. Vedi `CONTEXT.md` per architettura e roadmap, `BRANCHING.md` per il flusso di lavoro.
